# Grox Discord Bot

**Готовий Discord‑бот на Python** з набором функцій для спільнот: привітання, модерація, захист від спаму, система XP/рівнів, тикети підтримки, базові інформаційні команди та health‑endpoint.

---

## 📋 Опис

| Функція | Опис |
|--------|------|
| **Привітання/Прощання** | Надсилає embed‑повідомлення в канал `WELCOME_CHANNEL_ID` при приєднанні/виході учасника. |
| **Модерація** | `/ban`, `/unban`, `/kick`, `/mute`, `/warn`, `/warnings`. Усі дії записуються у PostgreSQL. |
| **Анти‑спам** | Видаляє повторювані повідомлення (>3 рази за 5 сек) або повідомлення з >5 посиланнями, попереджує/мутить. |
| **XP/Рівні** | За кожне повідомлення випадковий XP (1‑5). При досягненні порогу – підвищення рівня. `/rank`, `/leaderboard`. |
| **Тікети** | `/ticket open <subject>` створює приватний канал для користувача + роль Support. `/ticket close` закриває та зберігає історію. |
| **Базові команди** | `/help`, `/ping`, `/serverinfo`, `/userinfo`, `/stats`. |
| **Локалізація** | Весь інтерфейс українською. |
| **Health endpoint** | HTTP‑GET `/` повертає `{"status":"ok","discord_ready":true/false}`. |

## 🚀 Встановлення

### 1. Клонування репозиторію
```bash
git clone https://github.com/yourusername/grox-discord-bot.git
cd grox-discord-bot
```

### 2. Віртуальне оточення
```bash
python -m venv .venv
# Linux/macOS
source .venv/bin/activate
# Windows
.venv\Scripts\activate
```

### 3. Встановлення залежностей
```bash
pip install -r requirements.txt
```

### 4. Налаштування середовища
Створіть файл `.env` (скопіюйте `.env.example`) і заповніть:

```
DISCORD_TOKEN=Ваш_токен_бота
DATABASE_URL=postgresql://user:password@localhost:5432/discord_bot
WELCOME_CHANNEL_ID=123456789012345678
SUPPORT_ROLE_ID=987654321098765432
PORT=8080   # (необов'язково) порт для health‑endpoint
```

### 5. Підготовка бази даних
```bash
# Приклад для локального PostgreSQL
psql -U ваш_користувач -c "CREATE DATABASE discord_bot;"
# Таблиці створюються автоматично при запуску бота.
```

### 6. Запуск бота
```bash
python main.py
```

Бот підключиться до Discord і одночасно запустить HTTP‑сервер на вказаному `PORT`. Перевірити його працездатність можна зайшовши у браузер за адресою `http://localhost:PORT/`.

### 7. Тести
Тести в цьому репозиторії не включені (вимоги — лише три файли). При необхідності їх можна додати окремо з використанням `pytest` та `pytest-asyncio`.

## 🛠️ Технічна інформація

| Технологія | Версія |
|------------|--------|
| Python | 3.11+ |
| discord.py | 2.3.0 |
| asyncpg | 0.29.0 |
| aiohttp | 3.9.0 |
| python-dotenv | 1.0.0 |

- **Асинхронність**: весь код написаний з використанням `async/await`.
- **База даних**: PostgreSQL, підключення через `asyncpg` пул.
- **Логи**: файл `logs/bot.log` (ротація 1 МБ, 5 резервних файлів). Усі винятки та важливі події записуються.
- **Обробка помилок**: глобальний `on_app_command_error` – повідомлення користувачу та запис у лог.
- **Безпека**: всі секрети беруться лише з `.env`. У коді немає жорстко прописаних токенів чи ID.

## 🧭 Додаткова інформація

- **Команди модерації** доступні лише користувачам з відповідними правами Discord.
- **Тікет** створює приватний текстовий канал, видимий лише користувачу‑заявнику та ролі `Support`.
- **XP** – рівень підвищується за формулою `xp_needed = 100 * level^2`.
- **Health endpoint** можна моніторити будь‑яким сервісом (Prometheus, UptimeRobot тощо).
